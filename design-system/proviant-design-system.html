Review

Design Critique

Honest, actionable feedback on the current product across visual polish, consistency, and information hierarchy.

Overall Score: 6.5 / 10 — Solid foundation, needs refinement

The product has a clear purpose and the green brand color is distinctive. The information architecture is logical. However, there are significant opportunities to sharpen visual hierarchy, increase consistency across desktop/mobile, and make the experience feel more premium and "fresh/natural" as intended.

✓ Strength
Clear brand identity
The green-and-warm-gray palette is distinctive and appropriate for a food/pantry app. The logo mark is clean and memorable. Brand color is applied consistently as the primary action color.
✓ Strength
Semantic status system
The Expired → Critical → Expiring Soon → Fresh hierarchy is logically sound. Red, orange, amber, green maps naturally to urgency. This is the core interaction model and it's well conceived.
⚠ Issue
Status badges are too heavy
Current "Expired" and "Critical" badges use filled red/orange backgrounds with dark borders. They scream too loudly on every row — this creates visual anxiety. 52% expired means half the table is red. Softer pill badges (light tint backgrounds) reduce noise while preserving meaning.
⚠ Issue
Typography lacks hierarchy
Body text, labels, helper text, and metadata all feel the same weight. The system-default font (Inter/system-ui) is generic. A more humanist, slightly warmer font like DM Sans reads better for a food/home app and pairs perfectly with DM Mono for barcodes/codes.
⚠ Issue
Login screen is sparse and dated
The login page has no visual personality — two stacked inputs in a box on a white background, with the sign-in and sign-up sections oddly grouped. No brand atmosphere. No context for what the app does. Should feel welcoming and fresh.
⚠ Issue
Dashboard stats lack visual rhythm
The stat cards use inconsistent sizing. The all-red "52.4%" expired card is jarring because it's the most dominant visual — but that stat indicates failure. Consider reframing the dashboard to celebrate successes (savings, waste prevented) while surfacing urgency through a more focused alert section.
⚠ Issue
Mobile product list truncates badly
In the mobile list view, product names and thumbnails are cut off ("Nut", "Ore", "Pri", "Bar"). The image thumbnail area shows only a tiny placeholder corner. The mobile list needs a rethought layout: skip the image thumbnail on mobile, let the name breathe, and show the expiry prominently as a number (−19 days in red is good, keep that).
✦ Suggestion
Filter chip row is overloaded
The products page has two rows of filter controls — status filters AND location filters. This reads as two separate systems crammed together. Consider collapsing them into a single multi-dimensional filter panel, or use tabs for status + a location dropdown. Fewer controls, cleaner interface.
✦ Suggestion
Recipe page: "View Recipe" CTA is buried
The "View Recipe ↗" button uses a ghost/outline style and sits at the very bottom of the card, after many ingredient tags. Since this is the primary action, it should be more visually prominent — consider a solid green button or a hover-state overlay on the card image.
✦ Suggestion
Add product modal: tab switcher looks flat
The Manual/Camera tab switcher in the modal uses a segmented control style but the active state (full button) is indistinguishable from a primary button. Use an underline tab or a proper pill-style segmented control that's clearly a switcher, not a CTA.
✦ Suggestion
Empty states missing
No empty state screens are visible. When the pantry is empty, or a filter returns no results, or a recipe search finds nothing — these are important moments for user guidance and brand personality. Design empty states for each key screen.
✦ Suggestion
Mobile quick action banner is excellent
The green "Scan a product" CTA on mobile dashboard is your strongest piece of UX. It's prominent, contextual, and action-oriented. Extend this pattern — show contextual quick actions on other screens too (e.g. "3 items expiring soon — view them" on dashboard when waste rate is high).

Foundation

Design Principles

🌿
Fresh by default
The interface should feel clean, airy, and slightly organic. Warm backgrounds, humanist type, and nature-adjacent greens — not clinical, not tech-bro.
🎯
Urgency without anxiety
Alert states must be clear and readable, not alarming. Tinted backgrounds over solid fills. Reserve saturated red for truly expired items, not for the entire UI when 50% is expired.
⚡
Scan-first interactions
The barcode scan is the fastest path to adding products. Every screen should make this action reachable in one tap. Desktop keeps "+ Add product" always visible in the header.
